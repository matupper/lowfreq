LOWFREQ

An invite-only guide to the local underground music scene. Dark by default — built for browsing at night, at shows, in the dark. The visual language borrows from show flyers, xeroxed zines, and hand-stamped entry, not early-internet nostalgia.

concept

Where this comes from

The reference point is physical show ephemera — flyers stapled to poles, riso-printed zine covers, wrist stamps at the door — not 2003-era web design. This keeps the nostalgia authentic to the subculture and keeps the UI from aging into a dated trend.

embrace

Paper, ink, stamps

Flat matte surfaces, hairline and dashed rules, ink-stamp motifs for verification moments, slight imperfection (rotation, uneven borders) used sparingly.

avoid

Literal early-web

No tiled backgrounds, blinking text, comic sans, gradients, glitter cursors, or skeuomorphic browser chrome. Reads as costume, not culture.

02 — type

Typography

Anton carries every headline and event title — condensed, blunt, unmistakably gig-poster. Special Elite is a secondary accent face, reserved for stamped/verification moments only, never for general headlines. Inter carries all body copy. IBM Plex Mono handles anything that reads like it's printed on a ticket stub.

03 — motif rules

How much "handmade" is too much

Imperfection is the signature, but it has a budget. These rules keep it from tipping into gimmick.

  • yesRotate event/flyer cards -1° to 1°, never more. Never rotate buttons or body text.
  • yesUse dashed/perforated dividers for card and section breaks instead of hard rules.
  • yesReserve the ink-stamp animation and Special Elite type for one moment: getting verified/invited in.
  • noNo hand-drawn or "wobbly" fonts for body text — readability wins over character there.
  • noNo more than one accent color per screen (pink OR red, rarely both together).
  • noNo pure black backgrounds in dark mode — always the warm near-black, never #000.
